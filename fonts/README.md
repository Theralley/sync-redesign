# Fonts

`DMSans[opsz,wght].ttf` — DM Sans, the variable font (axes: optical size 9–40, weight 100–1000),
version 4.004 (`gftools[0.9.30]` build), Copyright 2014 The DM Sans Project Authors
(https://github.com/googlefonts/dm-fonts), designed by Colophon Foundry and Jonny Pinhorn.
Licence: SIL Open Font License 1.1, `OFL.txt` (the copy distributed with the font at
https://github.com/google/fonts/tree/main/ofl/dmsans). Source of this file: the same Google
Fonts distribution (the font file's own name table says version 4.004).

Used by `tools/glyphs.py`, which instances it at weight 560 and optical size 14 and turns the
glyph outlines into vector shapes for the Home screen's headings ("Telefon", "Navigation",
"Media", "Klimat"). No font is embedded in the car's files; only the outlines, as shapes.
